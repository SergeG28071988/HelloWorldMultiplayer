# HelloWorldMultiplayer

Учебный проект: простой мультиплеер на Unity с Netcode for GameObjects (NGO).

Игроки подключаются к одной сессии, видят друг друга и взаимодействуют.

## Стек

- Unity 6.3 LTS
- Netcode for GameObjects
- Unity Transport

## Что реализовано

- Подключение нескольких клиентов (Host / Client)
- Сетевой игрок — спавнится при подключении
- Каждый клиент управляет только своим персонажем
- Синхронизация позиции
- Сетевое взаимодействие, видимое всем игрокам

## Запуск

1. Клонировать репозиторий
2. Открыть в Unity Hub (Unity 6.3 LTS)
3. Дождаться импорта пакетов
4. `Window → Multiplayer Play Mode` → добавить 2 игрока → **Play**
5. В одном окне нажать **Host**, в другом — **Client**
